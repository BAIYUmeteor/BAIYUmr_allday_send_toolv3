B站直播间工具 v3.0 完整便携版
============================

🎯 功能特色：
- 直播间状态监控
- 弹幕发送功能  
- 开播自动问候语
- FFmpeg录播功能
- 图形化GUI界面

🚀 启动方式：
Windows用户：双击 start_v2.bat 或 bilibili_tool_v2.exe
Linux用户：运行 ./start_v2.sh

⚙️ 首次使用：
1. 设置B站账号凭证（菜单选项3）
2. 配置录播参数（菜单选项7）
3. 设置开播问候语（菜单选项6）

📁 文件说明：
- bilibili_tool_v2.exe - 主程序
- *.dll - 所有必需的运行库
- bilibili_tool_config.json - 配置文件
- recordings/ - 录播文件目录

💡 提示：
- 此版本包含所有依赖，可在任何Windows电脑运行
- 确保目标电脑已安装FFmpeg（用于录播功能）
- 程序完全便携，不写注册表，不污染系统

v2.1：修复了直播间在线人数显示异常
v3.0：增加独立监测，退出检测不会阻塞程序
